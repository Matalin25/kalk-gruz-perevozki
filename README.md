# Калькулятор сборных грузоперевозок (PWA)

Веб-приложение для расчёта стоимости доставки **сборного груза** и оформления
онлайн-заявки на перевозку. Работает как устанавливаемое PWA-приложение
(можно «установить» на компьютер/телефон и пользоваться офлайн).

---

## 1. Назначение

- Пользователь выбирает города отправления/получения, тип груза, габариты,
  вес и дополнительные услуги.
- Приложение считает стоимость и срок доставки.
- Пользователь оформляет онлайн-заявку; она уходит диспетчеру на
  **matalin@inbox.ru** (через Formspree), копия — клиенту, если указан e-mail.

---

## 2. Возможности

- Тёмный современный интерфейс с анимациями (переключение темы/чипов, подсчёт цены).
- Расчёт по направлениям (ставка ₽/кг) и типу груза.
- Учёт объёмного веса, минимальной стоимости, доп. услуг и онлайн-скидки.
- Загрузка актуального прайса с Яндекс.Диска + офлайн-режим на встроенных данных.
- Форма онлайн-заявки с подтверждением «Заявка успешно отправлена».
- Устанавливается как приложение (PWA), кэшируется и работает без интернета.

---

## 3. Технологии

- HTML + CSS + Vanilla JS (без сборщика и без фреймворков).
- [SheetJS (xlsx.full.min.js)](assets/js/xlsx.full.min.js) — чтение прайса `Прайс.xlsx`.
- Service Worker + Web App Manifest — офлайн и установка (PWA).
- Formspree — приём онлайн-заявок (AJAX-отправка). Резерв — письмо через `mailto:`.
- Локальный запуск — PowerShell-сервер `serve.ps1` (`http://localhost:8080`).

## 5. Запуск локально

1. Дважды щёлкните **`Запустить калькулятор.bat`** (или выполните `serve.ps1`).
2. Откроется браузер на `http://localhost:8080`.

> `localhost` считается «безопасным» контекстом, поэтому установка PWA и
> service worker работают. Запуск через `file://` (двойным щелчком по `index.html`)
> не рекомендуется — часть возможностей недоступна.

## 7. Источник данных (прайс)

- Встроенные данные — в `assets/js/data.js` (`DEFAULT_DATA`).
- При старте приложение пытается загрузить свежий `Прайс.xlsx` с Яндекс.Диска
  (`meta.sourceUrl`, лист «Данные для копирования») через публичный API и
  пересобрать таблицу направлений (`parsePriceRows`).
- Если сеть недоступна — работает офлайн на `DEFAULT_DATA`.
- В прайсе есть колонки с датами (числовые форматы), поэтому парсер помечает и
  игнорирует такие ячейки (`cellDates`, `isDateCell`).

Ключевые настройки прайса (`data.js → settings`):

| Параметр                 | Значение | Смысл                              |
|--------------------------|----------|------------------------------------|
| `volumetricDensity`      | 250      | Плотность для объёмного веса, кг/м³|
| `minCharge`              | 1500     | Минимальная стоимость перевозки, ₽ |
| `onlineDiscountPercent`  | 12       | Скидка за онлайн-заказ, %          |
| `defaultRatePerKg`       | 24       | Ставка по умолчанию, ₽/кг          |
| `defaultDays`            | 3        | Срок по умолчанию, дней            |
| `tempExtraDays`          | 1        | Добавка к сроку для реф. груза     |

## 8. Логика расчёта (`app.js → calculate`)

1. **Объём** = максимум из введённого и рассчитанного по габаритам (`Д×Ш×В×мест`).
2. **Объёмный вес** = объём × `volumetricDensity`.
3. **Расчётный вес** = max(фактический вес, объёмный вес).
4. **Ставка** — по направлению «откуда-куда»; если такого нет — `defaultRatePerKg`.
5. **Перевозка** = расчётный вес × ставка, но не ниже `minCharge`.
6. **Коэффициент типа груза**: обычный `×1`, негабарит `×1.35`, реф. `×1.5`.
7. **Срок** — из направления (+`tempExtraDays` для реф.).
8. **Доп. услуги** суммируются.
9. **Скидка онлайн** −12%; итог — к оплате.

## 9. Онлайн-заявка (Formspree)

Поток: кнопка **«Отправить заявку»** → модальное окно с полями →
AJAX-отправка на Formspree → экран подтверждения.

- Endpoint и почта задаются в `data.js → meta`:
  ```js
  orderEmail: 'matalin@inbox.ru',
  orderEndpoint: 'https://formspree.io/f/xvkzrbjj',
  ```
- В отправку добавляются спец-поля Formspree:
  - `_subject` — тема письма (например «Заявка ЗК-… — Москва → Казань»),
  - `email` — адрес для ответа (reply-to),
  - `_cc` — копия клиенту (если он указал e-mail),
  - `_gotcha` — honeypot от спама.
- Номер заявки формируется как `ЗК-ГГГГММДД-NNNN`.
- **Резерв:** если сервер недоступен, заявка открывается в почтовом клиенте
  пользователя через `mailto:` (с пометкой на экране подтверждения).

### Настройка на стороне Formspree (важно)

1. Аккаунт/форма должны быть активны (иначе форма отвечает `403 Form not active`).
2. Адрес получателя добавить и **подтвердить** (Account → Emails),
   указать целью формы (Workflow → Email).
3. Если провайдер получателя блокировал письма Formspree — разблокировать адрес:
   `https://formspree.io/unblock/matalin@inbox.ru`.
4. На бесплатном тарифе есть лимит заявок в месяц.

## 11. PWA / офлайн

- `manifest.webmanifest` — имя, иконки, цвет темы, режим `standalone`.
- `sw.js` — кэширует ресурсы приложения (`cache-first`), запросы к Яндекс.Диску
  и все не-GET (в т.ч. POST заявки) идут напрямую в сеть.
- Версия кэша: `kg-calc-v2`. При изменениях ресурсов её нужно поднимать,
  чтобы у пользователей обновилась версия.

---

## 12. Известные нюансы

- Скрипты `.ps1` без кириллицы: PowerShell читает их как ANSI, поэтому русский
  текст внутри `.ps1` может превратиться в «кракозябры».
- Отправка заявки не работает через `file://` (нет валидного Origin) — используйте
  локальный сервер или боевой сайт.
- Иконки PWA и favicon находятся в `assets/img/`.
